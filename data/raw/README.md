# Raw data

`AZ_ValleyFever_Original_ADHS_Cases_2015_2025.xlsx` is the original ADHS event-date case workbook (one sheet per year, 2015 to 2026 year-to-date). It is kept exactly as received; no case counts were edited.

The larger raw files are not committed here: daily EPA PM10 files by year (2015–2026), PRISM yearly climate extracts (2015–2026) with county centroids, and AZMet daily station files. They are kept in the team's shared Google Drive folder and can be re-downloaded from the public sources listed in the main README.
